# v0.4.0 — trust foundations (P1)

First tagged release. Ends the 0-tags/0-releases state; gives SDK version
bumps something to track.

## Added

- `LICENSE` (MIT) — the README's MIT grant is now actually shipped (P1-1).
- `.github/workflows/ci.yml` — minimal CI: `go build ./...` + `go vet ./...`
  + `go test ./...` and MCP `tsc --noEmit` on every PR and push to main (P1-2).
- `scripts/vault_index.py` + `scripts/graph_build.py` — the vault indexer,
  vendored in-repo (stdlib-only, `--dry-run`/`--reindex`); Quick Start Option A
  and the project-structure diagram fixed to match (P1-4, fixes M4/M6).
- `docker-compose.override.yml.example` — versioned live-only config; `up.sh
  verify` now fails cleanly (with `VERIFY-FAIL` lines) when required live
  bindings are absent, and no longer aborts mid-verify on a dead health
  endpoint under `pipefail` (P1-5, mitigates R5/R4).
- `docs/adr/0002-*.md`, `0003-*.md`, `0004-*.md` — first three (retroactive,
  Proposed) ADRs: Chroma-over-pgvector, 1536d pin, file-graph-over-Postgres
  (P1-6).
