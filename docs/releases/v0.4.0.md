# v0.4.0 — security + trust + growth (P0+P1+P2)

First tagged release. Ends the 0-tags/0-releases state; gives SDK version
bumps something to track.

## Security (P0)

- Fail-closed auth: refuse open non-loopback listen without credentials
  unless `VECTORIZER_ALLOW_OPEN=true` (local-dev only); `/health` reports
  auth mode.
- gRPC parity: API-key/JWT auth interceptor, loopback-only bind
  (`GRPC_BIND`, default `127.0.0.1`), loud failure on listen/serve errors.
- JWT workspace scoping resolved per route (param/query/body) with
  handler-level ownership checks; global search is admin-only.
- `/code/index` jailed to `CODE_INDEX_ROOT` (symlink escape rejected,
  `workspace_id` validated); webhook SSRF guard (public-IP only) with
  bounded-timeout client and capped in-flight deliveries.
- `/messages/upload` capped at 100k with proper error receipts; Chroma
  empty/shape-mismatch query results return empty instead of panicking.
- Single version source `internal/version` (0.4.0); **768d Nomic canonical,
  1536d Qwen opt-in** everywhere (dims, chunking max 6000, Chroma 1.0.0
  pins); all published ports loopback-bound; live IPs/paths/email scrubbed
  to placeholders + private-`.env` values.

## Trust foundations (P1)

- `LICENSE` (MIT) — the README's MIT grant is now actually shipped.
- `.github/workflows/ci.yml` — minimal CI: `go build ./...` + `go vet ./...`
  + `go test ./...` and MCP `tsc --noEmit` on every PR and push to main.
- `scripts/vault_index.py` + `scripts/graph_build.py` — the vault indexer,
  vendored in-repo (stdlib-only, `--dry-run`/`--reindex`); Quick Start
  Option A and the project-structure diagram fixed to match.
- `docker-compose.override.yml.example` — versioned live-only config;
  `up.sh verify` fails cleanly (with `VERIFY-FAIL` lines) when required
  live bindings are absent, checks env-parameterized paths (no hardcoded
  live IPs), and no longer aborts mid-verify on a dead health endpoint
  under `pipefail`.
- `docs/adr/0002/0004` accepted as-is (Chroma-over-pgvector,
  file-graph-over-Postgres); **ADR-0003 (1536d pin) is SUPERSEDED by the
  P0-1 dim decision above** — see the supersession notice in that file.
